# ADPTS

A modern, polished web application for dataset analysis, audit workflows, and administrative operations. Built with React and Vite, ADPTS provides an interactive interface for exploring datasets, reviewing audit information, and managing key platform activities from a single dashboard experience.

## ✨ Features

- Interactive dashboard for monitoring datasets and audit activity
- Dataset exploration and detail views
- Audit logs and image-related review workflows
- Admin and enhanced admin panels for management tasks
- Responsive UI with modern component styling
- Fast development workflow powered by Vite

## 🧰 Tech Stack

- React
- Vite
- TypeScript-friendly JavaScript setup
- Tailwind-style UI components
- React Router
- Modern UI libraries and icons

## 🚀 Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173/
```

### Build for production

```bash
npm run build
```

## 📦 Deployment

This project is ready to be deployed as a frontend application to platforms such as GitHub Pages, Netlify, Vercel, or any static hosting provider.

For static hosting, deploy the generated build output after running:

```bash
npm run build
```
